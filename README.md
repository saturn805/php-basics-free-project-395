# Генератор паролей (PHP)

[![hexlet-check](https://github.com/saturn805/php-basics-free-project-395/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/saturn805/php-basics-free-project-395/actions)

Соберите небольшое, но настоящее приложение — генератор паролей с проверкой надёжности. Оно придумывает пароли из выбранных наборов символов и оценивает, насколько надёжен любой пароль. Проект закрепляет основы программирования (строки, числа, условия, циклы, функции с параметрами) и собирается по шагам. Никаких библиотек и настройки окружения — писать и запускать код можно прямо в браузере.

Учебный проект Хекслета: https://ru.hexlet.io/programs/php-basics-free

## Использование

<!-- Добавьте примеры запуска и запись asciinema — именно это смотрит работодатель -->

Запуск осуществляется с помощью команды:
```bash
php main.php
```
Пример вывода:
```text
== Генерация паролей ==
буквы и цифры:    5vjehYzZEzZ0
со спецсимволами: X@qzNBCMdbAejoX8

== Проверка надёжности ==
abc        -> Слабый пароль (оценка 1 из 5)
abcdef1234 -> Средний пароль (оценка 3 из 5)
Abcdef123! -> Очень надёжный пароль (оценка 5 из 5)
```
